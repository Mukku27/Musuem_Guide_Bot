### Museum Guide Robot with RFID-Based Artifact Detection and Sign Language Support

#### Overview
This project involves designing a **museum guide robot** to enhance visitor experiences. The robot navigates along a predefined track, identifies artifacts using RFID technology, and provides voice-based information about the artifacts. Additionally, it supports accessibility for deaf and mute visitors through **sign language recognition** and displays translated text on an LCD screen.

#### Features
1. **RFID-Based Artifact Detection**:
   - Identifies artifacts using RFID tags placed near each display.
   - Provides pre-recorded voice descriptions for detected artifacts.

2. **Voice Interaction**:
   - Allows visitors to ask artifact-related questions using voice commands.
   - Responds with audio answers based on pre-trained data.

3. **Sign Language Detection**:
   - Includes a camera module to detect and interpret sign language gestures.
   - Displays translated text on an LCD screen for accessibility.

4. **Track Following**:
   - Utilizes line-following sensors or predefined trajectories to navigate through the museum.

5. **Accessibility**:
   - Offers a multi-modal interaction system catering to visitors with hearing and speech impairments.

#### Hardware Components
- **Microcontroller**: NXP EdgeReady RT117H
- **Sensors**:
  - RFID Reader
  - Camera Module (for sign language recognition)
  - Microphone (for voice commands)
- **Outputs**:
  - LCD Display (for text-based information)
  - Speaker (for voice responses)
  - Motors (for movement)

#### Applications
- Museums: Enhances accessibility and interactivity by providing hands-free, voice-guided tours.
- Exhibitions and Historical Sites: Offers educational support for interactive tours.
- Schools: Assists in making learning more engaging and inclusive.

#### Benefits
- Integrates multiple accessibility features like RFID tracking, sign language recognition, and voice interaction.
- Provides location-based information delivery, avoiding complex localization systems.
- Enhances visitor engagement with advanced multi-technology solutions.
